🖥️ Цифровое наследие: История развития ЭВМ в СССР и России

Интерактивное веб-приложение-хранилище, посвященное эволюции отечественной вычислительной техники — от первых ламповых машин до современных микропроцессорных систем.

🔗 Живое демо: https://evm-history-project-deiv.amvera.io/
🎯 Цель проекта

Создать единую базу данных ключевых отечественных ЭВМ, позволяющую не только изучать их историю, но и проводить наглядный сравнительный анализ технических характеристик различных поколений устройств.
✨ Ключевые возможности

    Интерактивный каталог: Просмотр списка легендарных ЭВМ (МЭСМ, БЭСМ, Сетунь, Эльбрус и др.) с фильтрацией и сортировкой.

    Сравнение "в лоб": Уникальный инструмент для сравнения двух выбранных машин по быстродействию, объему памяти и энергопотреблению.

    Детальные карточки: Подробная историческая справка, информация о главных конструкторах и уникальные фото каждой машины.

    Управление данными (CRUD): Полноценная административная панель для добавления новых записей и удаления неактуальных прямо через интерфейс.

    Облачное хранилище: Все данные надежно хранятся в PostgreSQL и доступны из любой точки мира.

🛠 Технологический стек
Backend

    Java 21 / Spring Boot 3 — ядро приложения.

    Spring Data JPA — работа с базой данных.

    PostgreSQL — надежное реляционное хранилище.

    Maven — сборка и управление зависимостями.

    DTO & Mappers — разделение слоев данных для безопасности и гибкости.

Frontend

    React + Vite — быстрый и отзывчивый пользовательский интерфейс.

    CSS3 (Flexbox/Grid) — современная адаптивная верстка.

    Hooks (useState, useEffect) — управление состоянием приложения.

DevOps & Infrastructure

    Docker & Docker Compose — контейнеризация всех компонентов системы.

    Amvera Cloud — облачный деплой и хостинг базы данных.

    GitHub — контроль версий.

🏗 Архитектура

Приложение построено по классической клиент-серверной архитектуре:

    Database Layer: PostgreSQL хранит структурированные данные об ЭВМ.

    API Layer (REST): Spring Boot контроллеры отдают данные в формате JSON.

    Client Layer: React-приложение визуализирует данные и взаимодействует с API.
